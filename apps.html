● BUILT INTO THE WINDOWS CLIENT

Power, not prompts.

→ 01

Kill switch always on

If the tunnel drops, the network drops with it. Packets do not leak in the gap. No "advanced" toggle to find — it's the default.

→ 02

LAN access stays on

Local devices on your home network keep working while the tunnel is up. Printer, NAS, smart-home gear — all reachable. One-click toggle if you want it off.

→ 03

Post-quantum-ready, by default

Every connection uses a hybrid post-quantum key exchange. No setting to find, no premium upsell. Quantum-era privacy on the lifetime free plan.

→ 04

Self-contained installer

One installer. No separate driver to chase down. No second VPN client to install. Sign in, click Connect, you're done.

→ 05

DNS that doesn't leak

Name lookups travel inside the tunnel. OS-level DNS is firewall-blocked while you're connected, so a misconfigured app can't accidentally reveal what you're visiting.

→ 06

True peer isolation

Other users on the same connection cannot reach your device. Independent layers of network enforcement, verified end-to-end on every release.
