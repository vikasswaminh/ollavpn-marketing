[PHASE 12: BLUE BACKGROUND RESIDUE PURGE ("RED LOGO WITH BLUE BACKSIDE" FIX)]
  - Problem Identified:
      * When user clicked navbar buttons (e.g. Technology, Apps, Free VPN), the logo appeared
        as a red squircle with an unsightly blue rim/halo peeking out from behind it.
      * Investigation revealed that 22 marketing templates in ollavpn-marketing contained an
        inline <style> rule:
        .brand-mark { background: url("data:image/svg+xml;...fill='%236366F1'...") !important; }
      * Because the red squircle <img> was nested inside <span class="brand-mark">, the browser
        rendered both: the blue background SVG and the red image, creating the layered artifact.
  - Engineering Resolution:
      * Completely eradicated every instance of %236366F1 and 6366f1 inline SVG backgrounds across
        all 29 marketing HTML templates and styles.css.
      * Set .brand-mark { background: none !important; } and .ug-logo-icon { background: none !important; }.
      * Replaced all wrapper spans with direct <img> tags:
        <img src="/logo.png" srcset="/logo.png 1x, /logo@2x.png 2x" alt="OllaVPN Logo"
             width="40" height="40" class="brand-img"
             style="width: 40px; height: 40px; border-radius: 8px; display: block; flex-shrink: 0;" />
      * Rebuilt all 199 Astro pages, synced assets, committed, and deployed to Cloudflare Pages.
  - Commits: 889e235 (blog), 9cc4d5e (marketing)
