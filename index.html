● THE HANDSHAKE

Hybrid by design.
Forward-secret on every session.

OllaVPN does not replace classical cryptography — it mixes it with a post-quantum key exchange on every connection. If either side of the hybrid holds up, your session stays private.

  • NIST-standardized post-quantum key exchange
  • Continuous re-keying — forward secrecy on every session
  • Hybrid by default, not an opt-in advanced setting
  • Session secrets never traverse the wire in the clear
